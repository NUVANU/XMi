# Optional document rereview

Use only on the Owner's explicit request. It is a second reading of the current design, not a prerequisite for XSpec export.

1. Read the current project and call the advertised xmi_spec_review_start with its exact version, a new idempotency key and the genuine native session selector. Optionally supply interview_module for that module's current statements, directly linked settings and common context documents. Otherwise the Agent receives readable specification documents; it does not receive the full Product Model. A schema-valid compiled candidate is currently required to prepare these documents.
2. When host_job is returned, launch one host Agent with its exact task_name, message and fork_turns none. Follow its bounded material-reading instructions. Do not steer it, edit its answer or start replacement Agents after timeout.
3. Reuse the original start key/version/session/module to collect once. Never pass reviewer JSON as authority. Status is read-only and supports finding pagination.
4. Present grounded issues together with their source quotes, impact and suggestions. Show questions about missing material and per-finding verification notes separately. No covered item/file/edge/scope enumeration is required; a bad finding does not discard the other grounded suggestions. Extra unresolved references are follow-up hints, not verified facts.
5. Findings are advice. Even BLOCKING severity cannot confirm product changes, change readiness or grant formal assurance. Let the Owner decide which suggestions to adopt through the existing confirmation flow. Empty findings do not mean PASS.

Project/version and actual native Agent/material sources are checked. Host permissions remain inherited; this path does not prove permission isolation or exhaustive coverage. Old strict runs remain historical records under their original schema. Generic hosts without this adapter remain unavailable; continue the normal compile/validate/export workflow with truthful limits. Do not configure providers, billing, credentials or a new review platform.
