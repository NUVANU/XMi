# 平台与证据范围

| 范围 | 当前状态 |
| --- | --- |
| 本地 SQLite/MCP | 自动化覆盖创建、确认、拒绝、幂等、回滚、重启恢复和导出约束 |
| Codex 模块确认 | 一次真实 16 项完整展示、真实回复、GRANTED、commit 及回读成功；所有异常路径未穷尽 |
| Codex 新公开配置工具 | 仍需干净接收端安装验收；历史首次使用报告不替代新工具验收 |
| WorkBuddy | 官方支持 STDIO；具体版本的表单、Skill 安装与完整访谈未实测 |
| Linux/macOS | CI 配置覆盖 Linux，实际结果以 GitHub 运行为准；真实宿主未验收 |
| ChatGPT 网页/手机 | 此包不提供远程 HTTPS 服务或已发布 App |
| XUi/XDev | 契约测试不等于真实运行时验收 |
| 独立审查 | 不可用时保持 UNAVAILABLE，不用自评冒充独立通过 |

依赖安装及模型服务可能需要网络。产品状态保存在用户选择的本地目录；宿主/模型隐私政策另行适用。FAST_VALIDATION 只面向原型规格，所有模式均保留来源与明确确认。
