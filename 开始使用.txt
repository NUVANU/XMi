XMi V0.1.2 — 2026-11-13

这是本地 Skills + MCP 源码，不是独立桌面程序。
准备 Node 24.20.0 / npm 11.19.0，进入仓库根目录执行：
  npm ci --omit=dev --ignore-scripts
  npm run check

新安装与升级分别按 docs/public/INSTALL.md 操作。已有数据需备份并保留原路由，不覆盖运行中的数据库；新连接后核对实际版本。不要通过编辑信任记录跳过宿主原生信任入口。

默认确认回复为“确认”，旧回复兼容。只列本次待处理项，未变化的已确认内容沿用。方案确认后自动生成同版 24 章架构，并按支持宿主的已有能力进行建议性独立内容评审。导出仍需对确切包取得授权。

详细功能与中英文切换见 README.md / README.zh-CN.md；当前验收范围见 docs/public/PLATFORMS.md。GitHub 源码不附 node_modules、真实产品数据库、私人聊天或机器配置。
